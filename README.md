# Dhaman for Android

Download the latest stable app for your country:

| Country | Download |
| --- | --- |
| Saudi Arabia | [dhaman-sa.apk](https://github.com/Ak-3d/dhaman-downloads/releases/latest/download/dhaman-sa.apk) |
| Yemen | [dhaman-ye.apk](https://github.com/Ak-3d/dhaman-downloads/releases/latest/download/dhaman-ye.apk) |

The two are separate apps that sign in to different servers, so pick your own
country's. You can also [view all releases](https://github.com/Ak-3d/dhaman-downloads/releases).

Those APKs work on any phone. Each release also has two smaller downloads per
country: `dhaman-<country>-arm64-v8a.apk` for 64-bit phones (most phones from
recent years) and `dhaman-<country>-armeabi-v7a.apk` for older 32-bit phones.
If one of those says it can't be installed, use the main APK instead.

Open the APK on your Android phone to install it. Android may ask you to allow
your browser to install apps from this source. Keep the existing installation
when updating so your app data stays on the device.

Each release includes its changes and a `SHA256SUMS` file for checking the
downloads. Contact your app administrator if an update cannot be installed.
