# Dhaman Yemen for Android

Download the [latest stable APK](https://github.com/Ak-3d/dhaman-ye-downloads/releases/latest/download/dhaman-ye.apk), or [view all releases](https://github.com/Ak-3d/dhaman-ye-downloads/releases).

That APK works on any phone. Each release also has two smaller downloads:
`dhaman-ye-arm64-v8a.apk` for 64-bit phones (most phones from recent years)
and `dhaman-ye-armeabi-v7a.apk` for older 32-bit phones. If one of those says
it can't be installed, use the main APK instead.

Open the APK on your Android phone to install it. Android may ask you to allow
your browser to install apps from this source. Keep the existing installation
when updating so your app data stays on the device.

Each release includes its changes and a `SHA256SUMS` file for checking the
download. Contact your app administrator if an update cannot be installed.
